# Rajeshwari Portfolio

Static portfolio page built to match the [Figma design](https://www.figma.com/design/0PVBF8a8X5kln0qFRddOp1/Untitled?node-id=1-39).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

- `index.html` — page sections (hero, about, projects, skills, contact, thank you)
- `css/styles.css` — layout, colors, and typography from Figma tokens
- `public/images/` — assets exported from Figma
- `public/images/projects/` — per-project thumbnails (Triplinx, Camptemgarh, Homedoctor, Flowdesk, AllRecipes, Audiotree)
